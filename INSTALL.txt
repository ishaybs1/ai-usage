AI Usage Tracker — install (macOS 13+)
=======================================

A menu-bar app that shows your personal Claude Code + Cursor spend, with a daily
notification and a Cost Coach. Everything stays on your Mac — nothing is uploaded.


SIMPLEST INSTALL (one paste) ★
------------------------------
1. Download this zip to your ~/Downloads folder.
2. Open Terminal, paste this ONE line, press Return:

cd ~/Downloads && Z=$(ls -t AIUsageTracker*.zip | head -1) && ditto -x -k "$Z" /tmp/aiu && xattr -dr com.apple.quarantine /tmp/aiu/AIUsageTracker/AIUsageTracker.app && rm -rf /Applications/AIUsageTracker.app; cp -R /tmp/aiu/AIUsageTracker/AIUsageTracker.app /Applications/ && mkdir -p ~/Library/LaunchAgents && cat > ~/Library/LaunchAgents/com.aiusagetracker.login.plist <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.aiusagetracker.login</string>
  <key>ProgramArguments</key><array>
    <string>/usr/bin/open</string><string>-ga</string>
    <string>/Applications/AIUsageTracker.app</string>
  </array>
  <key>RunAtLoad</key><true/>
</dict></plist>
PLIST
launchctl bootout "gui/$(id -u)/com.aiusagetracker.login" 2>/dev/null; launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/com.aiusagetracker.login.plist && open /Applications/AIUsageTracker.app && echo "Done — 🧠 is in your menu bar and will auto-start at login."

That's it. It installs to /Applications, skips the Gatekeeper warning, launches now,
and sets it to open automatically on every restart (via LaunchAgent — no System Events
or Apple Music permission prompts).

Look for the  🧠  in your menu bar (⌘-drag to reposition).


PREFER CLICKING? (manual)
-------------------------
1. Unzip → drag AIUsageTracker.app into /Applications.
2. RIGHT-CLICK it → Open → Open (needed the first time only).
3. To auto-start: System Settings → General → Login Items → + → pick the app.


WHAT IT READS (all local, read-only)
-------------------------------------
• Claude Code usage:  ~/.claude/projects/*.jsonl   (est. — priced at list rates)
• Cursor usage:       your existing Cursor login    (actual charged amount)
Each person sees only their own numbers.

DAILY DIGEST
------------
"Notify me on this Mac" is on by default — a local notification each day with your
spend + a tip. Change the hour (or add a Slack channel) in 🧠 → Cost Coach.

TROUBLESHOOTING
---------------
• No 🧠 icon: it may be hidden — ⌘-drag other menu-bar icons to reveal it.
• Cursor shows "n/a": sign into Cursor on this Mac, then reopen the app.
• Turn off auto-start: `launchctl bootout gui/$(id -u)/com.aiusagetracker.login` and
  remove `~/Library/LaunchAgents/com.aiusagetracker.login.plist` (or use Login Items).
